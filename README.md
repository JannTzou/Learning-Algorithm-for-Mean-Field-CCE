# Numerical Results

This directory contains figures generated by the numerical experiments for the paper:

> Optimal Coarse Correlated Equilibria in Mean Field Games:
> Linear Programming and No-Regret Learning.

## Figures

- `flocking.png`: convergence results for the flocking benchmark.
- `emissions_cce.png`: learned optimal coarse correlated equilibrium for the emissions-abatement game.
- `emissions_social_welfare.png`: emissions-abatement results including the moderator's social-welfare objective.

The corresponding implementation is contained in the `src/mfcce` package. Reproduction scripts and experiment configurations will be added to the `experiments` directory.
